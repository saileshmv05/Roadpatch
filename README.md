--INSTALLATION STEPS--

1)DOWNLOAD THE ZIP
2)HAVE REQUIREMENTS.TXT AND roadpulse_app.py IN SAME FOLDER
3)TURN ON TERMINAL I VS CODE
4)RUN:
     py -m pip install -r requirements.txt
     $env:GOOGLE_OAUTH_CLIENT_ID = 
     $env:GOOGLE_OAUTH_CLIENT_SECRET = 
     $env:GEMINI_API_KEY = 
     $env:GOOGLE_MAPS_API_KEY = 
     streamlit run roadpulse_app.py
5)it should open the website

You can run the website : https://roadpatch.streamlit.app/
